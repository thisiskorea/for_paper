description: Hugging Face Daily Papers Top 3를 분석하고 정리해서 마크다운으로 저장
---

다음 작업을 수행해주세요:

1. Hugging Face Daily Papers API (https://huggingface.co/api/daily_papers)에서 오늘의 Top 3 논문을 가져오세요.

2. 각 논문에 대해 다음 정보를 수집하세요:
   - 제목
   - 저자
   - ArXiv ID 및 링크
   - 초록 (abstract)
   - Upvotes

3. 각 논문의 초록을 분석하고 한국어로 다음 형식으로 요약하세요:
   - **핵심 요약**: 2-3문장으로 논문의 핵심 내용
   - **주요 내용**: 3-5개 bullet point로 주요 기여와 방법론
   - **의의**: 연구의 중요성과 영향 (1-2문장)
   - **키워드**: 관련 키워드 3-5개

4. 다음 형식의 마크다운 파일을 `outputs/daily_papers_YYYY-MM-DD.md`로 생성하세요:

```markdown
# Daily Papers - YYYY년 MM월 DD일

> Hugging Face Daily Papers의 Top 3 논문을 분석한 리포트입니다.

---

## 1. [논문 제목]

**저자**: [저자들]

**링크**:
- [ArXiv](arxiv_링크)
- [Hugging Face](hf_링크)

**Upvotes**: X 👍

### 요약

#### 핵심 요약
[요약 내용]

#### 주요 내용
- [bullet point 1]
- [bullet point 2]
...

#### 의의
[의의 설명]

#### 키워드
키워드1, 키워드2, ...

---

[논문 2, 3도 동일한 형식으로]
```

5. 변경사항을 커밋하고 푸시하세요:
   - 커밋 메시지: "📚 Daily papers update: YYYY-MM-DD"
   - outputs/ 디렉토리의 새 파일을 추가하고 커밋

전문적이면서도 읽기 쉬운 한국어로 작성하고, 깔끔한 마크다운 포맷을 유지하세요.
